# Nexnet - Magyarítás Letöltések

Magyar játékfordítások gyűjteménye egy egyszerű, statikus letöltőoldallal. Az oldal tiszta HTML/CSS/JS, szerver nélkül működik, így GitHub Pages-en is futtatható.

Az oldal itt található: https://0p3n50urc3-f0r3v3r.github.io/forditasok/

## Elérhető magyarítások

| Játék | Verzió | Állapot | Fordítók |
|---|---|---|---|
| Murderous Pursuits | 1.7.0 (Beta 5, dedikált szerver csomaggal) | 100% | P373R, Mosquito |
| Barony | 4.2.1 (GOG) | 100%, Gemini + kézzel lektorált | P373R, Gamini |
| Pummel Party | 1.14.1j (Beta 9) | 100% | P373R, Mosquito, BemBee (lektorálás) |
| Windward | 2025 (UPDATE3) | ~98% (néhány szerveroldali elem nem fordítható) | P373R, SlejmUr |
| Escape from Tarkov (SPT emulátor) | 3.10.x | 100% lefordítva, ~60-70%-ban lektorálva | P373R, Sikozu + az eredeti SPT fordítók |

A részletes leírás, telepítési információk és képernyőképek az oldalon (`index.html`), a telepítési útmutató pedig az egyes archívumokban található.

A magyarításokat szabadon letöltheted, módosíthatod és terjesztheted, de ne állítsd, hogy egyedül te készítetted őket. Kérjük, a fordítók nevét tartsd meg.

A fordítások részben gépi fordítást is tartalmaznak, de nagyrészt kézzel lektoráltak és több személy tesztelte őket. Elírások vagy félrefogalmazások ennek ellenére előfordulhatnak.
